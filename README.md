# WILD / STORIES — Image Slider

Galeria interativa de animais feita com **React**, **Vite** e **Tailwind CSS**, com navegação circular entre slides.

## Funcionalidades

- Navegação circular entre imagens pelos botões anterior e próximo
- Troca de slides usando as setas `←` e `→` do teclado
- Indicadores clicáveis e contador do slide atual (`01 / 05`)
- Layout responsivo com recursos básicos de acessibilidade (`aria-label`, `aria-current` e `aria-live`)

## Tecnologias

- React
- Vite
- Tailwind CSS v4
- Lucide React

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

3. Acesse o endereço exibido no terminal (por padrão, `http://localhost:5173`).

## Scripts disponíveis

- `npm run dev` — inicia o ambiente de desenvolvimento
- `npm run build` — gera o build de produção
- `npm run preview` — pré-visualiza o build gerado
- `npm run lint` — executa o linter (`oxlint`)
